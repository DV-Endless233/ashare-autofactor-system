# 第一性原理启动模板

## 每轮起始检查清单

dvcoder 在进入语义空间前，必须先做以下步骤。每一步都需要在输出中体现。

### Step 1: 停一下

**从第一性原理出发。**

在开始思考之前，先说出这句话。目的：强制切断对上一轮结论/外部报告/会议纪要的无意识继承。

### Step 2: 定义经济学逻辑

用一句话说明：**这个因子在经济学上想捕捉什么？**

模板：
```
经济学逻辑：______________________________
（例如：高自由现金流的企业意味着管理层有更多资源用于分红/回购/扩张，因此市场应给予更高估值）
```

### Step 3: 识别单因子结构

确认因子表达式是单一经济含义的加减乘除，不是多个 zscore 的线性组合。

模板：
```
候选表达式：_________________
是否为单因子：是 / 否
经济学名称：____________
```

### Step 4: 检查门控需求

默认不加门控。除非有明确的**经济学理由**。

模板：
```
是否需要门控：是 / 否
门控理由（如是）：______________________________
（只有这种情况可以加：分子分母同时为负导致比值为正，经济含义矛盾）
```

### Step 5: 检查变量映射

```
所用财务字段：______________
字段覆盖率（如未检查，先做数据覆盖检查）：_________
字段口径（TTM/单季/N年滞后）：_________
```

### Step 6: 进入算子空间

只有确认以上 5 步全部清晰后，才开始写代码。

## 禁止行为

- ❌ "上一轮用了 zscore(A)+zscore(B)，这一轮加上 zscore(C) 试试" → 已违反单因子规则
- ❌ "IR=1.2 还行，加个门控看能不能到 1.5" → 门控必须有经济学理由，不是调参工具
- ❌ "外部研报用了这种组合，所以我们也试试" → 只学方法，不套结论
- ❌ "先跑一下看看结果再决定方向" → 语义空间必须先清晰，再进算子空间
