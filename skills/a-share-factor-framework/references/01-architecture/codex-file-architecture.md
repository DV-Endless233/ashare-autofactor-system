# `*_codex.py` 文件结构口径

## 标准结构
1. 顶层最小 import
2. `class Xxx_codex(...):`
3. `__init__`
4. `initdataclass_`
5. `sigconstructperiods_`
6. `if __name__ == '__main__':`
7. 回测尾部 import 与执行

## 文件职责
- 这是叶子层，不是共享公式层。
- 负责把原子输入 + 共享算子组装成一个可缓存、可回测、可诊断的最终因子。
- 保持薄，不要变成新的父类或脚手架仓库。

## 应避免
- 大量通用函数内联在文件中。
- 只有壳，没有明确数学定义。
- 在 `__main__` 里掺杂与因子定义无关的临时实验代码。
