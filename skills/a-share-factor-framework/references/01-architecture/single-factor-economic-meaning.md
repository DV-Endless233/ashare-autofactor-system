# 单因子与经济学含义 — 判断指南

## 核心原则

因子必须能从**单一经济学含义**出发，用一级运算（加减乘除）构成。不能用多个不同经济含义的 zscore 做线性加权或任意系数组合。

## 判断标准

**单因子 ✅**：能用一个有经济学含义的名称概括的因子。
**多因子组合 ❌**：需要用"xxx的zscore+yyy的zscore-zzz"才能描述的。

## 示例分析

### ✅ 单因子（通过）

| 因子 | 表达式 | 经济学含义 |
|---|---|---|
| 自由现金流 | FCF = OCF - CapEx | 经营现金流减去资本开支后的自由现金流，单一经济含义 |
| 现金利润率 | OCF / NetProfit | 每单位净利润对应的经营现金流，衡量盈利的现金质量 |
| 资产周转率 | Revenue / TotalAssets | 每单位资产创造的收入，衡量资产使用效率 |
| 杠杆比率 | TotalDebt / TotalAssets | 资产中负债占比，衡量偿债风险 |
| 毛利率 | GrossProfit / Revenue | 收入中毛利占比，衡量定价能力 |

### ❌ 多因子组合（不通过）

| 因子 | 表达式 | 为什么不行 |
|---|---|---|
| 经营+资本惊喜 | zscore(OCF) + zscore(CapEx) - penalty(Debt) | 三个因子线性叠加，系数为什么是1不是0.5？无经济学依据 |
| 多维度质量 | zscore(Profitability) + zscore(Safety) - zscore(Growth) | 同样是人为赋权，系数缺乏经济学解释 |
| 加权组合得分 | 0.3×zscore(A) + 0.4×zscore(B) + 0.3×zscore(C) | 系数是任意选的，无法从经济学上论证 |

## 边界情况处理

### 1. 什么时候可以有不同的量纲放在一起？

允许：一级运算中的减法/除法对两个不同财务量做运算，如果结果有明确经济学含义。
- `FCF = OCF - CapEx`：两个现金流量的减法，结果"自由现金流"是公认财务概念
- `CashRatio = Cash / CurrentLiability`：除法得到"现金比率"，是公认偿债指标

不允许：对多个不同经济含义的信号做标准化后线性加权。
- `zscore(A) + zscore(B)`：标准化消除了量纲差异，但为什么A和B的权重都是1？

### 2. 什么时候可以加门控？

只有当**经济学含义本身就要求门控**时才可加：

- ✅ **必需的门控**：现金利润率 = OCF / NetProfit。当分子和分母都是负值时，比值反而为正——这扭曲了"现金利润率"的经济含义（亏损企业的现金利润比率为正毫无意义），**必须门控掉**这种情况。
- ❌ **禁止的门控**：基于历史回测最优区间切割的门控（如"当IC>0时取A，当IC<0时取B"）、基于参数网格选出的最优阈值门控。这些都是用历史数据调出来的，没有经济学依据，不能保证未来有效。

### 3. 什么是一级运算？

一级运算 = 无需对中间结果做标准化/归一化/正交化等后处理，直接用原始财务数据做加、减、乘、除得到的表达式。

- 一级运算 ✅：OCF - CapEx, OCF / NetProfit, Debt / Equity
- 非一级运算 ❌：zscore(OCF) + zscore(CapEx), rank(OCF) - rank(CapEx)

## 快速自查清单

在提交或审查因子时，逐项检查：

- [ ] 因子能否用一个有经济学含义的名称概括？（如"自由现金流"、"现金利润率"）
- [ ] 因子的表达式是否只有加、减、乘、除一级运算？
- [ ] 表达式中是否包含 zscore()、rank()、winsorize() 等标准化/排序处理后再组合？
- [ ] 如果用了条件/门控/奖励结构，是否有明确的经济学理由？（不是"历史回测表现好"或"参数搜索最优"）
- [ ] 如果去掉任何一个变量，因子的经济学含义是否崩塌？
- [ ] 因子的系数（如 1×A + 1×B 中的两个1）能从经济学上论证吗？

如果第3/4/5/6题有任何一个回答"是"或"不能"，因子很可能是多因子组合，需要重新设计。
