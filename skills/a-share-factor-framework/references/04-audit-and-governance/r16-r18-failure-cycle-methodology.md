# R16-R18 三连续失败轮的方法学记录

## 背景

R16（非经常性损益偏离扫描）→ R17（经营杠杆 YoY 弹性）→ R18（有效税率）三轮连续走完完整三阶段流水线但均未产出通过硬门槛的候选因子。以下是每轮的失败原因与下一轮方向决策记录，供后续反思"什么表达路径已充分验证不可行"。

## 每轮失败分析

### R16 — 非经常性损益偏离
- 方向：core_profit_retention、tax_anomaly、nonrecurring_scan
- 最佳：core_profit_retention（IC=0.0234, IR=1.28, ls=0.116）
- 失败原因：方向被 evaluator 判定为"太常规"，属于 nptopc/nptopcad 同维度内的延伸，未脱离已有信号族
- 下一轮决策：evaluator 建议换经济学维度，推荐经营杠杆 / 税率 / 短期信用视角

### R17 — 经营杠杆同比弹性
- 方向：operating_leverage_yoy_elasticity（B=op_1yrgro/totopinc_1yrgro, C=差分）
- B 结果：IC=-0.029, IR=-0.53, lsret=-0.036（反号后 IC=0.029, IR=0.53）
- C 结果：IC=0.007, IR=0.13, lsret=-0.006
- 失败原因：B 的分母 totopinc_1yrgro 在部分月份（2月）接近零，导致比值出现结构性尖峰不可修复；C 信号太弱（IR=0.13）
- 根因诊断：YoY 增速框架下分母近零是结构性问题，非参数可调
- 下一轮决策：evaluator 确认 YoY 框架内不可行，建议彻底换经济学维度

### R18 — 有效税率
- 方向：effective_tax_rate = inc_tax_ttm / tot_profit_ttm
- 语义预审：通过（经济学含义清晰、单因子合规、库无重复）
- 回测结果：IC=-0.002, IR=-0.19, lsret=-0.012（近乎噪声，反号也仅 0.002）
- 失败原因：信号强度不足，有效税率在截面上的区分力极低
- 下一轮决策：待 evaluator 决定——是 sign 方向问题还是该税负表达本身无效

## 关键模式

1. **语义预审通过不保证实现成功**（R18 语义通过但回测噪声）
2. **结构性根因 vs 参数可调**：R17 的分母近零是结构性问题，参数调不了；R16/R18 是信号强度/新颖性问题
3. **连续失败后的方向切换**：连续方向失败时应查因子库缺口（factor-library-gaps.md），选择完全不同的经济学维度，而不是在同维度内微调
4. **永不停机模式**：三轮连续失败后仍然继续创建 R18，不会因为失败就停止循环
